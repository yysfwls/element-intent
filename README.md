# Element Intent

一个最小 Chromium 扩展：点击扩展图标后依次标注多个网页元素，输入修改意图，并一次复制给 AI 编程工具。

适合正在使用 Codex、Claude Code、Cursor 等 AI 编程工具开发网页，并且 AI 已能读取项目代码的用户。它只负责把“页面上要改哪里、想怎么改”整理成可复制的定位描述，不读取源码，也不会直接修改网页项目。

## 功能

- 悬停高亮并点击选择网页元素。
- 为多个元素分别记录修改意图。
- 自动生成元素文本、语义、区域、唯一 DOM 路径和稳定属性。
- 一次复制全部修改，交给能够读取项目代码的 AI 编程工具。
- 自动过滤 URL 查询参数，并清理 SPA 路由切换后的失效标注。

## 本地开发

```bash
npm install
npm run dev
```

WXT 会启动用于 Chromium 的开发构建。也可以先执行：

```bash
npm run build
```

然后在 Chrome 或 Edge 的扩展管理页开启“开发者模式”，选择“加载已解压的扩展程序”，加载：

```text
.output/chrome-mv3
```

## 使用

1. 打开一个普通网页或本地开发页面。
2. 点击工具栏中的扩展图标，进入元素标注模式。
3. 悬停查看高亮范围，点击锁定元素。
4. 输入修改意图，点击“添加”，元素旁会留下编号标记。
5. 继续选择其他元素，或者点击编号编辑、更新和删除已有标注。
6. 点击页面右下角工具条中的“复制给 AI”。
7. 将剪贴板内容粘贴到能够读取当前项目代码的 AI 编程工具。

点击“取消”或在浮层打开时按 `Esc` 可以重新选择；再次点击扩展图标，或在选择状态按 `Esc`，可以临时退出标注模式。当前页面刷新前，再次开启仍会保留已有标注。

复制内容只包含页面源站与路径，不包含查询参数或普通 hash，避免把 URL 中的 token 等敏感值带给 AI。单页应用切换路由或元素被重新渲染后，对应的旧标注会自动移除。

## MVP 边界

- 只处理普通 DOM 元素。
- 不定位源文件，不调用 AI，不修改项目代码。
- 不支持浏览器内置页面、跨域 iframe、Canvas 和 WebGL 内部对象。
- 标注仅保留在当前页面内，刷新后清空；复制动作由用户主动触发。

## 技术栈

TypeScript、WXT、Floating UI、Vitest。
